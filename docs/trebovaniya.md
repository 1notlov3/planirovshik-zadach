# Требования к программе «Планировщик задач»

## Для кого программа
Для студента, который хочет планировать свои дела по неделям.
Программа работает на одном компьютере, без интернета и регистрации.

## Что должна уметь программа
1. Добавлять задачу в общий список задач.
2. Показывать общий список: номер, название, неделя и статус задачи.
3. Начинать новую неделю (неделя – период планирования).
4. Брать задачу из общего списка в текущую неделю.
5. Менять статус задачи: «надо сделать», «в работе», «готово».
6. Показывать итоги недели: сколько задач в каждом статусе и сколько
   процентов выполнено.
7. Хранить задачи и недели в файлах zadachi.csv и nedeli.csv.

## Ошибки ввода
Если название пустое, номер задачи или статуса неверный, программа пишет
об ошибке и ничего не меняет.
