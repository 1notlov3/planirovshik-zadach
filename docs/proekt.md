# Устройство программы

## Файлы
- planirovshik.py – программа;
- zadachi.csv – задачи (создаётся сам при первой задаче);
- nedeli.csv – недели (создаётся сам при первой неделе);
- test_planirovshik.py – проверки программы.

## Формат файлов
Поля разделены точкой с запятой.

zadachi.csv – номер;название;неделя;статус

    1;Прочитать главу по Git;1;готово
    4;Купить тетради;;надо сделать

nedeli.csv – номер;дата начала

    1;18.11.2026

## Функции программы
| Функция | Что делает |
|---|---|
| load, save | читают и записывают файл |
| add_task | добавляет задачу в общий список |
| show_tasks | выводит общий список |
| start_week | начинает новую неделю |
| find_task | ищет задачу по номеру |
| take_to_week | берёт задачу в текущую неделю |
| change_status | меняет статус задачи |
| week_result | считает задачи недели по статусам |
| show_week_result | выводит итоги недели |
| main | показывает меню |
