# Планировщик задач

Учебный проект по дисциплине «Проектная деятельность в ИТ»
(Московский университет имени С.Ю. Витте), тема «Разработка программы
планировщика Agile для личного пользования».

Автор: Грачев Максим, группа о.ИЗДтс 23.1/БЗ-25.

Agile – это способ планировать работу короткими периодами, например
по неделе. Программа хранит общий список задач, позволяет начать неделю,
взять в неё задачи из общего списка, менять их статус и смотреть итоги недели.

## Как запустить

Нужен Python 3.10 или новее, дополнительные библиотеки не нужны.

    python planirovshik.py

Задачи сохраняются в файл `zadachi.csv`, недели – в файл `nedeli.csv`.

## Что умеет программа

1. Добавить задачу в общий список.
2. Показать общий список задач.
3. Начать новую неделю.
4. Взять задачу из общего списка в текущую неделю.
5. Изменить статус задачи: «надо сделать», «в работе», «готово».
6. Показать итоги текущей недели.
